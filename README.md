# 🎲 de-virtuel — Le Dé Virtuel

**Projet 1** du cahier des charges « 5 mini-projets JavaScript » (HTML / CSS / JS).

## Objectif
Créer un dé que l'on « lance » en cliquant sur un bouton. À chaque clic, un nombre
aléatoire entre **1 et 6** s'affiche en gros à l'écran.

## Livrables
- `index.html` : la structure de la page
- `style.css` : la mise en page
- `script.js` : toute la logique JavaScript

## Équipe
- **Développeur A** : structure HTML, style CSS, logique du tirage (base)
- **Développeur B** : bonus (symboles du dé ⚀⚁⚂⚃⚄⚅, deux dés + somme), animations, tests

On travaille tous les deux sur la **même branche**.

## Utilisation
Ouvrir `index.html` dans le navigateur, puis cliquer sur « Lancer le dé ».

## Notions utilisées
Fonctions · `Math.random()` · `getElementById` · `addEventListener` · `textContent`
